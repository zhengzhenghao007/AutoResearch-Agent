# 科研工作台界面重构

2026-11-06。复用 Next.js App Router、React、既有业务组件和 research-api。主入口 app/page.tsx → SessionWorkspace → EvidenceWorkspace；URL 的 run/stage 继续作为项目与工作区定位，保留未保存写作/资料的离开保护。

## 信息架构

- 顶栏提供品牌、当前页项目搜索、设置和账户入口。
- 左栏提供新建研究、工作台、文献库、阅读、选题比较、数据与图表、写作、研究执行及项目历史。
- 空白首页以研究问题输入和 PDF 上传为中心，快捷操作将用户带入现有业务入口。
- 项目内各工作区独立导航。项目概要、筛选、引用和高级审核按需展开。
- 独立研究执行视图复用 ResearchTasks，展示已完成步骤、整体进度、当前步骤、暂停和取消。工具调用与预算设置折叠。
- 设置展示现有会话、技能目录与后端配置方式，未有业务 API 的模型或 Prompt 编辑不展示可保存表单。

## 视觉

白色主画布 #ffffff、侧栏 #f5f6f8、文字 #20242b、次要文字 #667085、分隔线 #e5e7eb、强调色 #315fd3。使用现有本机无衬线字体栈，标题与正文统一。顶栏 64px、侧栏 232px；输入区强调留白，资料区域左对齐。主题变量为后续深色模式预留。移动端显示折叠项目列表、可横向滚动导航，正文保持单列。

## 验证

现有前端全量测试、类型检查、lint、生产构建。网页实际检查新项目、上传入口、项目切换、阅读、比较、数据、写作、设置与任务进度。移动端验证无页面横向溢出，并检查键盘焦点与错误反馈。自动研究只使用现有已授权执行接口，不改变后端业务语义。

## 本轮结果与边界

- 28 个前端测试文件、148 项测试通过；lint、类型检查、生产构建通过。
- 真实项目浏览器验证：阅读、比较、数据、写作入口；技能目录加载；执行页导航和刷新；账户展开；390px 移动端无页面横向溢出，无 JavaScript 异常。
- 上传、任务运行、写作保护等通过现有自动化测试覆盖，本轮未向用户项目上传测试文件或重新执行付费分析。
- 项目搜索仅过滤当前历史分页。手动分配 Skill、网页模型/Prompt 编辑、深色主题切换尚未实现；设置明确展示当前边界。
- 本轮未改变后端 API 或研究数据。
